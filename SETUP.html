ARQUIVOS DO PROJETO

📄 index.html
Lobby: Mestre cria sessão, players entram com código
📄 master.html
Painel do Mestre: vê fichas, rola dados, envia mensagens
📄 sheet.html
Ficha do jogador com sync automático para Firebase
📄 SETUP.html
Este guia de instalação

PASSO 1 — CRIAR PROJETO FIREBASE

01

Acesse console.firebase.google.com e faça login com sua conta Google.

Clique em "Criar um projeto", dê um nome (ex: cyberpunk-mesa), desative o Google Analytics (não é necessário) e clique em "Criar projeto".

PASSO 2 — ATIVAR REALTIME DATABASE

02

No painel do projeto, clique em "Compilação" → "Realtime Database" → "Criar banco de dados".

Escolha a região mais próxima (ex: us-central1) e selecione "Iniciar no modo de teste" (válido por 30 dias, depois configure as regras).

⚠ REGRAS DE SEGURANÇA (Após 30 dias):
No Realtime Database → Regras, use estas regras básicas para produção:

{ "rules": { "sessions": { "$sessionId": { ".read": true, ".write": true } } } }

PASSO 3 — COPIAR CONFIGURAÇÃO

03

No Firebase Console, vá em Configurações do projeto (ícone de engrenagem) → "Seus apps" → clique em "Web" (</>) para registrar um app.

Dê um apelido (ex: "mesa-online") e copie o bloco firebaseConfig que aparece. Será algo assim:

const firebaseConfig = { apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXX", authDomain: "meu-projeto.firebaseapp.com", databaseURL: "https://meu-projeto-default-rtdb.firebaseio.com", projectId: "meu-projeto", storageBucket: "meu-projeto.appspot.com", messagingSenderId: "123456789012", appId: "1:123456789012:web:abc123abc123" };

PASSO 4 — COLAR NOS 3 ARQUIVOS

04

Abra index.html, master.html e sheet.html em qualquer editor de texto (Notepad, VS Code, etc.).

Em cada arquivo, localize o bloco que começa com:

const firebaseConfig = { apiKey: "AIzaSyDEMO_substitua_sua_chave_aqui",

Substitua todo o bloco pelo que você copiou do Firebase. Salve os 3 arquivos.

PASSO 5 — HOSPEDAR OS ARQUIVOS

05

Os 4 arquivos precisam estar no mesmo servidor web. Opções gratuitas:

Opção A — GitHub Pages GRÁTIS FÁCIL
Crie um repositório público no GitHub, faça upload dos 4 arquivos, ative Pages em Settings → Pages → Branch: main.

Opção B — Netlify Drop GRÁTIS
Acesse app.netlify.com/drop, arraste a pasta com os 4 arquivos. Pronto — URL gerada na hora.

Opção C — Servidor Local
Se tiver Python: python3 -m http.server 8080
Acesse em http://localhost:8080. Só funciona na mesma rede local.

COMO USAR — FLUXO DA SESSÃO

MESTRE

1. Abra index.html → preencha seu nome → clique "CRIAR NOVA SESSÃO"
2. Você será redirecionado para o Painel do Mestre com um código tipo NEON-4729
3. Compartilhe esse código com seus jogadores
4. Veja as fichas dos jogadores no painel central, role dados e envie mensagens

JOGADOR

1. Abra index.html → preencha seu nome/handle e o código recebido
2. Clique "ENTRAR NA SESSÃO"
3. Sua ficha será aberta e sincronizará automaticamente a cada edição
4. Roladas de dados aparecem no chat do Mestre em tempo real

LIMITES DO PLANO GRATUITO FIREBASE

O Firebase Realtime Database gratuito (Spark) suporta:
100 conexões simultâneas · 1 GB de armazenamento · 10 GB/mês de transferência
Para uma mesa de RPG com 2-6 jogadores, isso é mais do que suficiente.
